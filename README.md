# Project Parrot

*A pet app by Astra.*

## Project Parrot

Capture the project, name the smallest next move, and choose when to come back.

## How to run

Open [project-parrot-20261008.html](project-parrot-20261008.html) directly in a modern browser. No install, server, account, or network connection is needed.

## What works

- Add and edit idea records with purpose-specific fields.
- Search, filter by status, advance a record, and delete with undo.
- Keep entries in this browser's local storage.
- Export a private JSON backup or Markdown worklist.
- Choose among all nine pet moods.

OneNote connection is planned. Paste ideas here; due reminders appear while this page is open.

## Data and limits

Records are stored only in the browser where you enter them. Clearing site data can remove them; export backups. Exported records can contain personal information and must stay outside this source repository. The page does not send entries to a server. The pet's mood is a display choice.

Project Parrot shows due reminders while the page is open. Periodic OneNote scanning and background notifications are not connected.
